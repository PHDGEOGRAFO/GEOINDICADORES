GIS STGO

Plataforma integrada de modelación territorial · v0.6.38

Modelación territorial para la planificación comunal

GIS STGO es una propuesta de modelación de la comuna de Santiago orientada a entregar herramientas para la planificación comunal mediante visores interconectados. Cada módulo desarrolla una arista particular del territorio —cartografía, indicadores, suelo, bibliotecas digitales y modelación 3D— dentro de una arquitectura común de consulta y análisis.

La plataforma integra información territorial para apoyar diagnóstico, gestión municipal, seguimiento y toma de decisiones, manteniendo independientes las fuentes y ciclos de desarrollo de cada visor.

Entorno de revisión. Los módulos no terminados se muestran como En proceso. Cada módulo se abre en una pestaña nueva para mantener disponible el INDEX de GIS STGO.
