Inventario en actualización

Catálogo Territorial de Coberturas GIS / GeoPackage

Se está realizando un nuevo control para determinar el inventario vigente de coberturas de la Biblioteca Digital Territorial. Durante esta revisión no se publica un conteo ni una carga parcial para evitar mostrar información desactualizada.

La arquitectura del módulo, el buscador, las fichas técnicas y el visor liviano propio de Biblioteca se mantienen preparados para sincronizar el inventario definitivo cuando termine el control.
