# Contrato técnico GeoIndicadores Web

- Aplicar KISS y mantener HTML, CSS, JavaScript y datos separados.
- Usar MapLibre GL JS y rutas relativas compatibles con GitHub Pages.
- Admitir escalas manzana, barrio, territorio y comuna.
- Mantener `COD_MZN`, barrio y territorio cuando corresponda.
- Mostrar gráficos solo para barrio y territorio.
- Distinguir valor original, normalización, dirección y rango.
- Permitir min–max, percentil y valoración inversa explícita.
- No incluir credenciales, datos personales ni claves API.
- Toda publicación requiere pruebas de consola, rutas, filtros y datos.
